# Life K-Line Final（琛南最终版）

这是基于 `curionox/lifekline` 思路，经多轮修改后固定下来的 **人生 K 线最终母版**。

以后为任何人生成“人生 K 线 / 流年趋势图谱”时，必须以本分支 `life-kline-final` 为唯一母版，不再从旧 `lifekline` 仓库重新开始。

## 固定调用方式

用户说以下任一表达时：
- 用人生 K 线最终版生成
- 用最终版人生 K 线
- 按我的人生 K 线母版生成

应先读取本分支的 `SKILL_FINAL.md`，然后以当前已验证源码为基准生成。

## 已验证源码入口

当前可运行基线由这些文件组成：
- `2002-12-12/index.html`：最终页面结构实例
- `2002-12-12/calendar.js`：100 年流年 / 大运时间轴实例
- `2002-12-12/model.js`：评分、十神、干支关系和 K 线模型实例
- `2002-12-12/app1.js` / `app2.js`：图表、账本、交互、导出与分享
- `styles.css`：最终视觉样式

这组文件是一份已经跑通的参考实现。未来生成新命主时，保留页面和交互体系，但必须重新计算并替换新命主对应的真太阳时、四柱、大运、十神、贵人规则和评分口径。

## 分支职责

- `life-kline-final`：只作为最终母版与生成规范。
- `main`：继续保存不同命主的公开成品网页。
- 旧 `lifekline`：只作为历史来源，不再作为新生成任务的起点。
