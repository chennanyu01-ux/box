# Life K-Line Final（琛南最终版）

这是基于 `curionox/lifekline` 思路，经多轮真实设备测试和交互迭代后固定下来的 **人生 K 线正式母版**。

以后为任何人生成“人生 K 线 / 流年趋势图谱”时，必须以本分支 `life-kline-final` 为唯一母版，不再从旧 `lifekline` 仓库、根目录旧页面或 `2002-12-12/` 示例重新开始。

## 固定调用方式

用户说以下任一表达时：
- 用人生 K 线最终版生成
- 用最终版人生 K 线
- 按我的人生 K 线母版生成

先读取 `SKILL_FINAL.md`、`PRODUCTS.md` 和 `products/INPUT_SCHEMA.md`，再按需要选择三个正式产品母版。

## 三个正式产品

### 1. Mobile HTML
路径：`products/mobile-html/`

手机端正式版 **Life K-Line Mobile v1.0**。来源于真实手机多浏览器迭代后最终确认的 v8 交互版本。支持单指拖动、双指连续缩放、轻触年份、双击复位、横屏行情工作台，以及综合 / 事业 / 财运 / 感情 / 贵人五线。

最终产物必须打包成一个自包含 `.html` 文件，不依赖 GitHub、CDN、服务器或网络。

### 2. Desktop HTML
路径：`products/desktop-html/`

电脑端正式版 **Life K-Line Desktop v1.0**。同样输出一个完全自包含的本地 HTML，针对宽屏、鼠标与触控板优化：鼠标拖动平移、滚轮围绕指针缩放、双击恢复百年总览、全屏查看；触控屏仍兼容双指缩放。

最终 HTML 可直接在 Chrome / Edge / Safari 等现代浏览器中从本地文件打开。页面主体不请求任何远程资源，因此用户是否在中国大陆、是否联网、是否使用 VPN 都不影响核心运行。

### 3. PDF
路径：`products/pdf/`

正式档案版 **Life K-Line PDF v1.0**。用于直接发送、长期保存和打印，是 HTML 之外的非交互备份交付。生成后必须逐页渲染检查。

## 统一数据原则

三个产品共用同一份已经计算完成的 JSON 数据包。出生信息、真太阳时、四柱、大运、100 年年度数据先统一计算一次，然后分别交给三个渲染器，避免手机版、电脑版和 PDF 出现数值不一致。

## 分支职责

- `life-kline-final`：正式母版、生成规范和版本历史。
- `main`：历史公开成品和必要的客户成品；不再作为运行时依赖。
- 旧 `lifekline`、根目录旧版与 `2002-12-12/`：历史参考，不再作为新生成任务起点。

GitHub 从现在开始主要承担 **源码保存与版本控制**。HTML 客户端本身是本地离线产品，不需要 GitHub 才能运行。
