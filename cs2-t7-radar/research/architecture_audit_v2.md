# T+7 架构审查与验收

审查基线：GitHub `chennanyu01-ux/box` 的 `cs2-t7-radar` 分支，提交 `a10b46228103657c15df5e1bad8a3c45229df261`。该目录全部 10 个文件均已读取。仓库其他目录是日历/命理网页，与雷达无依赖关系。

## 修正的问题

| 原问题 | 后果 | V2 处理 |
|---|---|---|
| 历史读取只下限、不限制截止时间 | 历史信号可能读取后来的行情 | 数据、元数据、社交证据、大盘均按可用时间过滤 |
| 精确裁掉 168 小时以前的数据 | 不规则采样时 7 日基准消失，缺失被当成零涨幅 | 保留每平台左侧锚点；限制锚点陈旧度；缺失为 null |
| `buff` 子串识别 | 可能把 BUFF.MARKET 或无关字符串当 BUFF163 | 明确平台别名，不接受子串匹配 |
| BUFF 缺失时返回其他平台中位数，字段却以 BUFF 命名 | 误导实际价格和收益判断 | BUFF 数值为空，禁止 BUY_CANDIDATE |
| 只看两端库存 | 一次撤单即可获得高分 | 净减少/总变动、有效更新数、连续覆盖、下降步数、单次下降占比 |
| 重复旧报价算新样本 | 虚增确认次数和库存持续性 | 特征按来源更新时间去重，保留首次可用时间 |
| 评分阶段只由当期阈值生成 | 无阶段记忆或转移确认 | 六状态重放、转移驻留确认、派发/崩盘立即生效 |
| 中文元数据刷新覆盖历史 | 未来元数据进入历史分组 | 元数据版本化；缺少当时版本时使用 canonical name |
| 基础目录只收印花/喷漆 | 样本选择偏差、漏掉多数商品 | 默认全目录，明确筛选配置 |
| 静态案例被标成高可信正样本 | 幸存者偏差和归因偏差 | 撤回原无来源高置信标签，建立证据登记 |
| 没有回测模块 | 无法知道解锁后的损益 | BUFF ask 入场、解锁后的首个有效 BUFF bid 退出 |
| `score` 也初始化 API 客户端 | 没有 Key 无法离线研究 | 离线评分、导入、回测不依赖 Key |

## 代码边界

`steamdt.py` / `collector.py` 读取接口；`db.py` 保存观察到的时序和元数据版本。`domain.py` 统一时间、平台与无效数值处理。`features.py` 计算库存与盘口特征，`state_machine.py` 重放状态，`context.py` 计算市场残差与同类对照。`attribution.py` 提供原因及事件/社交风险，`calibration.py` 用过去成熟标签估计 T+7 求购价相对报价带的经验分位数。`scoring.py` 汇总交易门槛。实时与历史统一调用 `engine.py`；`backtest.py` 负责交易模拟与 walk-forward。

数据库迁移只添加字段、索引和表，保留旧快照和手动禁用品种。状态重放窗口默认 21 天，前 7 天作为长基准预热；超出窗口的阶段历史不作永久身份标签。

## 验证与真实数据边界

测试覆盖未来数据不变性、重复来源更新、虚假库存回补、跨平台价格隔离、独立阶段转移、7 天内不可退出、第一求购报价退出、手续费、零求购量、缺失/右删失、训练标签成熟时间、分组去重、数据库迁移、离线命令和完整 walk-forward。

2026-09-12 实际联调：目录 44,387 项；已采样 206 项、2,379 条多平台盘口；归档大盘及两个印花的 BUFF K 线各 2,160 行。历史盘口从本次采集才开始，T+7 已观察退出数为 0。检查 100 个首批 T0 入场，其中 80 个具备模拟入场报价，另外 20 个不可执行；80 个 T+7 结果均未成熟。禁止据此报告策略胜率。

检验回测使用 `fee_rate=0.025`、额外 0.5% 滑点的显式情景；2.5% **未作为已确认的当前 BUFF 费率**写入正式配置，默认费率为空，实际决策须配置真实费率。

当前三部分均为可解释规则和经验统计，尚未训练成经过样本外验证的概率模型。没有历史 bid，不补造回报；没有可靠归因，不强行给“庄家型”高权重。

## 仍需真实数据解决的事项

1. 至少持续采集到完整 T+7/14/30 退出窗口，或导入有原始接收时间的历史 BUFF 盘口。默认滚动训练窗为 180 天，另需测试期。
2. 基础目录没有系列、总供应量、实际成交量；目前按官方英文标识提取类型/磨损/赛事，价格与挂单/求购数量作代理。完整系列/供应量必须以带可用时间的可靠补充数据导入。
3. 44,387 项按每分钟 100 项轮询，一轮约 7.52 小时。严格 24 小时库存形态主要依赖热点细采，粗扫不足会被拒绝。热点预算为每轮最多 30 项，预留新发现名额；不能宣称全部商品均达到信号所需采样密度。
4. 盘口顶价及求购总数没有逐档深度或真实成交确认，只能做单件报价模拟；资金容量、实盘滑点、提现费用另行验证。
5. 今日回溯抓取的帖子/K线，其 `available_at` 为今日，不准倒填为过去。需要当时的存档才能用于严格历史特征。

本地开发目录由 GitHub 指定提交的文件快照导入，并建立单独本地 Git 基线；它不是完整 `box` 仓库的历史克隆。不要从该本地基线强推远程历史。
