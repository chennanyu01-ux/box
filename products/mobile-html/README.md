# Life K-Line Mobile v1.0

Canonical mobile source. Build output is a single self-contained offline HTML file with no CDN or network dependency.

Interaction: one-finger horizontal pan, two-finger pinch zoom, tap to select a year, double-tap to reset the 100-year view, and a landscape K-line workspace. The source also supports the total K-line plus career, wealth, relationship and noble-support series.

Files in this directory are maintained as the mobile master. Recalculate each customer's data first, then reuse this UI and interaction layer.
